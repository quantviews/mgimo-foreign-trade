# Данные внешней торговли в Excel — инструкция для аналитиков

Как получать данные внешней торговли прямо в Excel и обновлять их одной кнопкой.
Без программирования — только меню Excel. Технический справочник — отдельно
([api-reference.md](api-reference.md)); эта инструкция для повседневной работы.

---

## Что понадобится (один раз)

**Персональный ключ (токен).** Это ваш «пароль» к данным.

1. Откройте в браузере **`http://217.26.28.186:8088/apikey/`** и войдите своей учётной
   записью Superset (той же, что для дашбордов).
2. Нажмите **«Выпустить токен»**.
3. Скопируйте показанный ключ вида `mgt_xxxxxxxx…` и сохраните в надёжном месте —
   **он показывается один раз**.

> Не видите кнопку, а написано «доступ по роли API»? Значит вашей учётке ещё не выдали
> доступ — напишите администратору, чтобы он добавил роль **API**.

Ключ личный — не передавайте его коллегам (у каждого свой).

---

## Подключение данных (один раз на файл)

1. В Excel: вкладка **«Данные»** → **«Получить данные»** → **«Из других источников»** →
   **«Из веб-канала OData»**.
2. В поле URL вставьте: **`http://217.26.28.186:8090/odata/`** → **ОК**.
3. Появится окно входа. Слева выберите **«Основной»**:
   - **Имя пользователя:** впишите что угодно (например, `token`).
   - **Пароль:** вставьте ваш ключ `mgt_…`.
   - Нажмите **«Подключиться»**.
4. В окне «Навигатор» слева — **две таблицы**: `trade` (строки торговли: стоимость,
   вес, количество) и `fizob` (индекс физического объёма — см. отдельный раздел ниже).
   Отметьте нужную (для начала **`trade`**) и нажмите **«Преобразовать данные»** (не
   «Загрузить» — сначала отфильтруем, чтобы не тянуть всё).

Откроется «Редактор Power Query» с таблицей данных.

---

## Отфильтровать нужный срез (важно!)

Данных очень много (миллионы строк), поэтому **сначала задайте фильтры**, а потом
загружайте. Фильтры ставятся мышкой — по стрелке ▼ в заголовке столбца.

- **Страна** — ▼ на столбце `STRANA` → **«Текстовые фильтры» → «Равно»** → впишите
  ISO-код страны (например, `CN` — Китай, `DE` — Германия, `TR` — Турция) → **ОК**.
- **Период** — ▼ на `PERIOD` → **«Фильтры даты» → «После…»** (например, `31.12.2023`)
  или **«В диапазоне»**.
- **Направление** — ▼ на `NAPR` → отметьте `ИМ` (импорт в РФ) или `ЭК` (экспорт из РФ).
- **Товар (ТНВЭД)** — ▼ на `TNVED2` (2 знака) или `TNVED4` (4 знака) → «Равно» →
  код группы (например, `27` — топливо).

Каждый фильтр добавляется шагом справа (в списке «Применённые шаги») — его можно потом
изменить (значок ⚙) или удалить.

Когда срез готов: вкладка **«Главная» → «Закрыть и загрузить»**. Данные лягут на лист.

## Что означают столбцы

| Столбец | Значение |
|---|---|
| `PERIOD` | месяц (первое число) |
| `NAPR` | направление: **ИМ** — импорт в Россию, **ЭК** — экспорт из России |
| `STRANA` | страна-партнёр (ISO-код) |
| `TNVED` | полный код ТНВЭД, `TNVED2/4/6/8` — по первым 2/4/6/8 знакам |
| `TNVED_NAME`, `TNVED2_NAME`, `TNVED4_NAME` | **названия товара** для соответствующего уровня кода |
| `STOIM` | стоимость, **доллары США** |
| `NETTO` | вес нетто, **килограммы** |
| `KOL` | количество в доп. единице (`EDIZM` — её название, напр. «ШТУКА») |
| `SOURCE` | источник (national / comtrade / nowcast) |
| `TYPE` | **fact** — факт, **pred** — прогноз (nowcast) |

> `KOL` имеет смысл только вместе с `EDIZM` (в разных товарах — разные единицы, их нельзя
> складывать между собой). Для сравнения объёмов используйте `NETTO` (кг) или `STOIM` (USD).

## Индекс физического объёма (таблица `fizob`)

`fizob` — отдельная таблица с **индексом физического объёма**: он показывает динамику
объёмов торговли относительно базового периода, очищенную от изменения цен (в отличие от
`trade`, где стоимость в долларах зависит и от цен). Подключение — то же самое, но в
«Навигаторе» выберите таблицу **`fizob`**.

**Как фильтровать** (мышкой по стрелке ▼, как в `trade`):

- **Уровень детализации** — ▼ на `tn_level`: `0` — итог по всей стране, `2` / `4` / `6` —
  по коду ТНВЭД в 2 / 4 / 6 знаков. **Сначала выберите один уровень** — иначе строки разных
  уровней смешаются.
- **Страна** — ▼ на `STRANA` (ISO-код: `CN`, `DE`, `TR`…). **Направление** — ▼ на `NAPR`
  (`ИМ` / `ЭК`). **Период** — ▼ на `PERIOD`.
- **Товар** — ▼ на `tn_code` (код на выбранном уровне, например `27` при `tn_level` = 2).

| Столбец | Значение |
|---|---|
| `PERIOD`, `NAPR`, `STRANA` | как в `trade` (месяц, направление, страна) |
| `tn_level` | уровень кода: `0` (вся страна), `2`, `4`, `6` |
| `tn_code` | код товарной группы на этом уровне (пусто на уровне `0`) |
| `tn_name` | название товара (для уровней `2` и `4`) |
| **`idx`** | **индекс физического объёма — главный показатель динамики** |
| `fizob`, `fizob_bp` | рабочие величины: текущий объём и объём базового периода (из них считается `idx`) |

> Для анализа берите **`idx`**. `fizob` и `fizob_bp` — промежуточные величины.

## Обновление и смена среза

- **Обновить те же данные:** вкладка **«Данные» → «Обновить всё»** — Excel заново скачает
  по текущим фильтрам.
- **Поменять фильтры:** **«Данные» → «Запросы и подключения»** → двойной клик по `trade` →
  измените шаг фильтра → **«Закрыть и загрузить»**.

---

## Если что-то не так

- **«Property … does not exist» или не хватает столбцов с названиями.** Excel запомнил
  старую структуру. Полностью **закройте Excel и откройте заново**, затем пересоздайте
  подключение (раздел «Подключение данных»).
- **Просит пароль снова / ошибка входа.** Проверьте, что выбран способ **«Основной»** и в
  поле **пароль** — ваш ключ `mgt_…` (имя пользователя — любое). Сбросить сохранённый вход:
  **«Данные» → «Настройки источника данных»** → выберите адрес → **«Очистить разрешения»**.
- **Долго грузит / зависает.** Скорее всего забыли фильтр — данных слишком много. Откройте
  запрос, добавьте фильтр по стране и периоду, затем загрузите заново.
- **Ключ потерялся или скомпрометирован.** Зайдите в кабинет
  (`http://217.26.28.186:8088/apikey/`) и нажмите **«Перевыпустить токен»** — старый
  перестанет работать.

## Коротко

1. Получить ключ в кабинете (один раз).
2. Данные → Из веб-канала OData → `http://217.26.28.186:8090/odata/` → Основной, пароль = ключ.
3. Выбрать `trade` (стоимость/вес/количество) или `fizob` (индекс физобъёма) →
   Преобразовать данные → **поставить фильтры** → Закрыть и загрузить.
4. Обновлять кнопкой «Обновить всё».
