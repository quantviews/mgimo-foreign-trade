# Проверка и обновление источников 18 ноября 2026 года

Обновлены локальные исходные и подготовленные данные. Общая DuckDB, nowcast, fizob и бюллетени в этом обновлении не пересчитывались. Сервер 146 не изменен.

## Национальные источники

- Индия: скачан сентябрь 2026 из MEIDB, оба направления, стоимость и натуральные показатели. Добавлено 7 427 строк: импорт России - 5 712 строк на 357,38 млн USD; экспорт России - 1 715 строк на 5 861,36 млн USD. Значения стоимости сверены с исходным CSV с учетом масштаба источника. Подготовлен и установлен `data_processed/in_full.parquet`; 640 418 исторических строк полностью совпадают с предыдущей версией. Дублей новых ключей нет. Нераскрытые количества и масса сохранены как пропуски. Реестр `metadata/national_release_coverage.json` дополнен сентябрем для обоих направлений. Октябрь MEIDB вернул нулевую заготовку, файл не сохранен.
- Турция: действующий сборщик TUIK BI подтвердил публикации по сентябрь 2026, 165 из 165 месяцев загружены. Сентябрь повторно скачан в соседнем проекте `turkey-foreign-trade`; все 4 915 строк совпадают с прежней выгрузкой. Подготовленный файл Турции в основном проекте не заменялся.
- Китай: локальные проверенные товарные выгрузки по сентябрь 2026. По опубликованной копии календаря онлайн-детализация октября запланирована на 20 ноября. Новая товарная выгрузка не скачана. Октябрьские сводные публикации не использованы вместо товарной детализации. Официальный DOC с календарем не удалось получить в текущем окружении; дата проверена по текстовой перепечатке календаря.

Календарь: [официальное объявление](https://www.mofcom.gov.cn/zcfb/zgdwjjmywg/art/2026/art_f1be0183462142a28dbd9fd727220e3e.html), [таблица дат](https://duiwaimaoyi.com/2025/12/7054.html).
