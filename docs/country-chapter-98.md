# Национальные названия группы 98

Группа 98 в общем справочнике ранее получила название китайской узкой позиции
«Товары низкой стоимости, ≤ 2000 юаней». Причина: перевод дочернего кода
копировался в отсутствующие родительские уровни. Это название неверно описывало
индийские данные.

Общее название теперь нейтральное: «Специальные товарные категории национальных
номенклатур». Для Индии отдельный заголовок: «Проектный импорт; лабораторные
химикаты; багаж пассажиров; личные отправления воздушным транспортом или почтой;
судовые припасы». Это проверенный русский перевод индийского заголовка, а не
заявление о составе конкретной поставки.

Источник: [DGFT, How to Export, страница PDF 21](https://content.dgft.gov.in/Website/HTE.pdf).
Исходный английский заголовок и ссылка сохранены в
`metadata/translations/country_chapters.json` и таблице `tnved_country_chapters`.
Национальная подпись применяется только к указанной стране и уровню 2, не к
дочерним кодам и не ко всем странам мира. При общем агрегировании API не разделяет
один код на несколько строк из-за разных национальных названий.

`scripts/rebuild_tnved_reference.py` обновляет справочники, представление торговых
данных и подписи в materialized fizob. Выполняется только локально. Объемы торговли,
масса, количество, nowcast и значения fizob при этом не пересчитываются.

В MCP национальный справочник доступен через
`reference(name="tnved", level=2, strana="IN")`. В демо-чат дополнительно
передается точный `code`, чтобы название вошло в проверяемые факты ответа.
Для нескольких стран вместе API сохраняет одну строку группы и нейтральное
название, не разделяя сумму по вариантам перевода.
