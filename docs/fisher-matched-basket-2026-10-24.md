# Fisher по сопоставимой корзине: локальный эксперимент

Расчёт выполнен на `tmp/china-revision-build/input.duckdb`, с обновлёнными
выгрузками Китая за июль и август. Прод и рабочая база не изменены.

Текущее окно: сентябрь 2025 - август 2026. База: январь - декабрь 2025.
Это звено к прошлому календарному году по подходу Тымченко, не обычный темп
год к году и не цепной индекс с исторической базой. Окна пересекаются.

Сохранены формулы A=Σv0, B=Σv, C=Σv0*r, D=Σv/r;
Q=sqrt(D/A*B/C), P=sqrt(C/A*B/D). ALL складывает слагаемые стран.
Пригодность измерителя требует покрытия 80% стоимости обоих окон. Индекс цены
вменяется по медианам логарифмов 6/4/2 знаков, затем направления, по всем странам;
минимум три ряда для товарных уровней, граница выброса - отличие в три раза.
При отсутствии собственного индекса и аналогов r не заменяется единицей.

Корзина содержит только ряды с известной неотрицательной стоимостью всех
12 месяцев каждого окна и одним источником на объединении окон. Неизвестная
стоимость не восстанавливается. Нулевые наблюдения сохраняются; отсутствие
строки не становится нулём. Строки с наблюдаемым нулём в обоих окнах не дают
вклада. Отсутствие количества при известной стоимости допускает вменение цены.

Отбор сопоставимой корзины - явное ограничение охвата относительно исходного
общего расчёта Тымченко. Его формулы и иерархия цен сохранены; исходный файл
и экспериментальные функции общего Fisher не изменены.

Покрытие - стоимость корзины / доступная стоимость всех записей среза в том же
окне; это не доля неизвестной полной торговли. imp=Σ(v+v0) для вменённых цен /
Σ(v+v0) корзины, как у Тымченко. В артефактах отдельно сохранены доли вменения
для каждого окна, число рядов, A/B/C/D, Q/P и источники медиан на уровне ряда.

Экспорт группы 27 в Китай имеет наиболее высокий охват доступной стоимости.
Импорт группы 27 охвачен узко: большой рост выбранной корзины нельзя переносить
на всю группу. Результаты ALL также описывают лишь сопоставимую часть торговли.
Низкий imp не компенсирует низкое покрытие стоимости.

Воспроизведение: `scripts/calculate_fisher_matched.R` принимает путь локальной
базы и новый каталог результатов. Проверка: `scripts/verify_fisher_matched.py`.
Успешные артефакты: `tmp/fisher-matched-basket-v2/summary.csv`, `summary.parquet`,
`series.parquet`, `verification.json`. Первая попытка в каталоге без суффикса v2
отклонена независимой проверкой из-за кодировки направлений в R на Windows;
её результаты использовать нельзя.

Проверены все восемь агрегатов: полные окна корзины, единый источник, конечные
положительные индексы цен, суммы A/B/C/D, imp, границы покрытия и Q*P=B/A.
Историческая цепь не строилась: для неё необходимо согласовать корзины и
декабрьские звенья отдельно, не склеивать текущий результат с общим fizob.
